# cortico-world-usage-relay · Token 账房

Coopanion 的 World 扩展：看 Coopanion 自己的 token 消耗，也管中转站的比价和账单。

> QQ 交流群：745879632（使用、报 Bug、提需求都来）

- 数据源：本机用量日志 `usage.jsonl`（默认在 companion 数据目录下，可用配置项 `usageFile` 或环境变量 `COOPANION_USAGE` 覆盖）。
- 纯本地统计，看板本身不产生任何模型调用。
- 功能：五张汇总卡（当日总量 / 当前小时进行中 / 峰值时段 / 缓存命中率 / 较昨日同期）、
  每小时柱状/折线图（叠昨日同期虚线、已发生时段均值线、当前小时蓝框、未发生小时灰底）、
  点柱子下钻「这一小时每分钟」、逐日历史表、模型分布表。
- 附带一个智能体工具 `tokenboard_usage`：主人问「今天用了多少 token」时，桌宠可以直接查。
- 「测速对照」「账单核对」「配置」三个页签：中转站对照台（RelayHub）的原生界面，不再内嵌网页。
  - 测速对照：顶部是醒目的「推荐用哪个」大卡（按品牌给结论、不同品牌不同配色）；中转站按品牌分组列出
    （可多选 → 一键批量测速），卡片上直接看「实扣 / 标价 vs 官方、延迟、万次省」；
    选中一个站后下方是测速表单（次数 / 预热 / max_tokens / 思考 / Prompt）与「当前目标最近一次结果」
    （首字延迟、p95 / 最差、解码速度、单次实测成本、同品牌延迟差、每万次省）＋ 站点实扣对账。
    添加 / 编辑中转站时品牌与模型联动，模型清单可按 API Key 从站点读取（只显示站点真有的模型），
    官方参考价与站点标价可分别「从站点读取」，
    支持按几折一键换算、设为该品牌基线。
  - 账单核对：最上面是「额度怎么买（计价基准）」——按中转站设直充（人民币 X 元买 Y 额度）或
    套餐（¥29.9 / 1 个月给 4000 万额度），自动折算「1 额度 ≈ ¥多少」，并比较两种买法哪个更划算；
    这是账单金额换算和跨站比价的前提。下面「获取账单」三个入口：
    直连同步（探测 + 令牌 / Cookie + 长脚本，脚本内联展开、可滚动、可复制）、
    粘贴导入（文本 / 剪贴板 / 文件；「采集脚本」弹窗给出自研后台专用的短脚本，三步照做）、
    手填汇总（请求数、站点金额、输入 / 输出 / 缓存命中 token，按顶部计价基准折算人民币）；
    左侧中转站按模型品牌分组并可筛选；下方是体检报告（按通过 / 警告 / 失败整行上色）、概览卡、
    模型分布、历史账单。
  - 配置：启动方式（自动 / 手动）、服务状态与「启动服务 / 关闭服务 / 重启服务 / 重新检测」，
    服务地址与 Python 路径，每日用量提醒阈值。
  - 服务是独立进程（`127.0.0.1:8770`）。默认手动启动；把「启动方式」改成自动后，
    Coopanion 起来约 3 秒会自动拉起它（不弹命令行窗口）。
  - 面板经 `world.invoke()` 由后端 Node 直连该服务（顺带绕开跨源限制与 CORS），浏览器不直接访问它。

## 内存

- 用量日志按 4MB 分块解析，不再把整个文件读进内存再 split：峰值内存从「文件的 2~3 倍」降到一块左右。
- 只保留按天/小时/分钟/模型聚合后的计数，不缓存原始日志行。
- 对照台服务是独立进程，不用时可在配置页关掉；不想它常驻就把启动方式留成手动。

## 口径

- 总量 = 输入 + 输出；「缓存命中」是输入中命中前缀缓存的部分（上游单独计费折扣）。
- 缓存命中率 = 缓存命中 ÷ 输入。
- 时间按本地区整点归档（usage.jsonl 的 ts 已带本地时区）。
